# Feature: 11区梯度条组件

## 功能概述

实现核心的11区梯度条视图组件，包括Zone标签、渐变背景、宽容度标记和测光点标记。这是应用最核心的视觉组件，直观展示测光结果在11区系统中的分布。

## 当前状态

- [x] 已完成

## 目标

创建一个可视化、交互式的11区梯度条，能够：
- 显示从纯黑到纯白的11个Zone
- 标示当前胶片的宽容度范围
- 显示所有测光点在Zone分布中的位置

## 详细任务

### Task 4.1: 创建 ZoneScaleView.swift 11区梯度条视图

**文件**: `LightMeter/Views/ZoneScaleView.swift`

**结构**:
```swift
struct ZoneScaleView: View {
    let minZone: Int        // 宽容度最小Zone
    let maxZone: Int        // 宽容度最大Zone
    let meteringPoints: [MeteringPoint]  // 测光点数组

    private let zoneLabels = ["0", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX", "X"]

    var body: some View { ... }
}
```

**实现内容**:

**A. Zone标签行**:
- 水平排列11个标签
- 标签内容：["0", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX", "X"]
- Zone V 标签特殊显示：
  - 字体：白色，semibold
  - 其他Zone：灰色 (#8E8E93)，regular
- 字体大小：10pt
- 水平分布：等宽分布
- 内边距：水平8pt

**B. 渐变条**:
- 高度：32pt
- 圆角：4pt
- 渐变：LinearGradient，从左到右
- 11个色阶对应11个Zone：
  ```
  Zone 0:  #000000 (纯黑)
  Zone I:  #1A1A1A
  Zone II: #333333
  Zone III: #4D4D4D
  Zone IV: #666666
  Zone V: #808080 (中灰)
  Zone VI: #999999
  Zone VII: #B3B3B3
  Zone VIII: #CCCCCC
  Zone IX: #E6E6E6
  Zone X: #FFFFFF (纯白)
  ```

**C. 宽容度标记**:
- 蓝色半透明遮罩
- 背景色：#007AFF，透明度 20%
- 边框：#007AFF，2pt
- 宽度：根据胶片宽容度计算 `(maxZone - minZone + 1) / 11 * 总宽度`
- 位置：根据 minZone 计算起始位置
- 圆角：4pt

**D. 测光点标记**:
- 形状：圆形
- 尺寸：16pt × 16pt
- 颜色：使用测光点的 color 属性
- 位置：根据 zone 值计算 `(zone + 0.5) / 11 * 总宽度`
- 垂直居中于渐变条
- 多个测光点在同一Zone时堆叠显示（略微错开）

**E. 整体布局**:
```
VStack(spacing: 8) {
    // Zone标签行
    HStack { ... }

    // 渐变条（包含宽容度标记和测光点标记）
    ZStack {
        // 渐变背景
        LinearGradient(...)

        // 宽容度标记
        GeometryReader { ... }

        // 测光点标记
        ForEach(meteringPoints) { ... }
    }
}
.padding(.vertical, 12)
.background(Color.black)
```

### Task 4.2: 实现渐变背景

- 使用 SwiftUI 的 `LinearGradient`
- 方向：从左到右（.leading → .trailing）
- 11个色阶使用 `Gradient(colors: [...])`
- 添加 `.cornerRadius(4)`

### Task 4.3: 实现宽容度标记

- 使用 `GeometryReader` 获取渐变条尺寸
- 计算每个 Zone 的宽度：`zoneWidth = totalWidth / 11`
- 宽容度标记宽度：`(maxZone - minZone + 1) * zoneWidth`
- 宽容度标记起始位置：`minZone * zoneWidth`
- 使用 `Rectangle()` 创建标记
- 添加边框和半透明填充

### Task 4.4: 实现测光点标记

- 使用 `ForEach(meteringPoints)` 遍历所有测光点
- 计算位置：`x = CGFloat(point.zone) * zoneWidth + zoneWidth / 2`
- 使用 `Circle()` 创建圆形标记
- 填充颜色：`Color(hex: point.color)`
- 尺寸：16pt × 16pt
