# Feature: 光圈快门联动控制

## 功能概述

在曝光参数栏中提供明确的光圈/快门联动交互。用户可以基于当前画面测光点选择光圈或快门优先，应用根据当前 EV、胶片 ISO 和标准曝光档位自动反算另一项参数。

## 目标

- 光圈和快门都可以从曝光参数栏直接选择。
- 选择光圈后进入光圈优先模式，快门根据测光结果自动联动。
- 选择快门后进入快门优先模式，光圈根据测光结果自动联动。
- 保留现有 Zone 高亮框快门拖动能力，拖动仍作为快门曝光偏移。
- 保留现有光圈锁定能力，并把它纳入统一的联动模式显示。

## 交互模式

| 模式 | 触发 | 固定项 | 联动项 |
|------|------|--------|--------|
| 自动联动 | 默认/解锁 | 无 | 根据测光点自动推荐光圈和快门 |
| 光圈优先 | 选择光圈 | 光圈 | 快门 |
| 快门优先 | 选择快门 | 快门 | 光圈 |

## 计算规则

- 使用当前测光点计算目标 EV。
- 有选中测光点时，优先使用选中点 EV。
- 无选中测光点时，使用所有测光点的平均 Zone/EV。
- 光圈优先：`快门 = f(目标EV, 光圈, ISO)`，吸附到标准快门档位。
- 快门优先：`光圈 = f(目标EV, 快门, ISO)`，吸附到标准光圈档位。
- ISO 始终来自当前胶片预设。

## UI 范围

- `ExposureInfoView`
  - 光圈项继续可点击，显示锁定状态。
  - 快门项改为可点击，显示锁定状态。
  - 顶部模式指示从自动/手动扩展为自动联动、光圈优先、快门优先。
- `ApertureSelectorView`
  - 保留现有标准光圈选择。
- `ShutterSelectorView`
  - 新增底部弹窗，列出标准快门速度。
  - 提供解锁快门按钮。
- `MainMeteringView`
  - 接入快门选择弹窗。

## 测试要点

- 给定 EV 和锁定光圈，能得到正确标准快门。
- 给定 EV 和锁定快门，能得到正确标准光圈。
- 选择光圈后模式变为光圈优先，快门更新。
- 选择快门后模式变为快门优先，光圈更新。
- 解锁后回到自动联动。
- Zone 条拖动快门偏移仍能更新显示，不破坏现有测光点移动逻辑。

## 验收标准

- 曝光参数栏中光圈和快门都可以打开选择器。
- 用户选择 `f/11` 时，快门按当前测光点自动变慢一档左右。
- 用户选择 `1/250s` 时，光圈按当前测光点自动开大一档左右。
- 模式和锁定图标显示清晰。
- 构建通过。
