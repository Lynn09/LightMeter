# 中央准心 LiDAR 测距

在取景画面中心显示中心连实的十字（没有外围圆环），距离以米为单位显示在取景框底部的标尺框内。
点击标尺框右侧的锁定按钮冻结距离（橙色及锁图标），点击解锁恢复测距。
中央十字不拦截点击，锁定操作由底部标尺框内的按钮处理；画面其余区域仍用于添加测光点。
距离用于辅助手动对焦，不参与曝光计算；距离基准是手机相机，不是胶片相机。

## 采集与失效处理

- 使用现有 AVCaptureSession 的后置 builtInLiDARDepthCamera，与实时测光共用相机。
- 为 LiDAR 选择支持深度的非像素合并视频格式，固定 1×，增加 AVCaptureDepthDataOutput。
- 保持预览的 aspect-fill 居中裁切；准心固定在预览区域中心，采样深度图中央 5×5 像素。
- 转换为 Float32 米制深度，按实际行字节数读取；拒绝相对深度及整体质量低的帧。
- 只接受 0.15–5 m 的值。这是本版保守的工作区间，不代表精度保证。
- 需要过半有效采样；邻域至少 80% 有效值处于同一表面，避免跨前后景边缘平均。
- 每秒最多更新十次，以五次移动平均平滑；目标明显变化时重置历史。
- 未锁定时，无效数据立即清空，超过 0.75 秒无更新清空。锁定值保留至用户解锁。
- 离开界面或进入后台时停止相机、清除读数与锁定状态；恢复后重新采集。
- 不支持 LiDAR、权限未允许或深度输出不可用时显示明确提示及 `— m`，不伪造距离。
- 先添加相机输入，再设置支持 30 fps 的视频/Float16 深度格式，避免添加输入时重新协商格式。
- LiDAR 配置失败或启动 3 秒后仍无视频帧时，自动回退到普通后置相机；回退失败显示错误及重试按钮。
- 延迟恢复任务由启动代次控制，切换后台或重启会话后不会误触发旧任务。
- 首次显示通过可取消的 task 请求启动，不依赖尚未稳定的 active 状态；inactive（如权限面板）不停止相机，仅 background 或界面消失时停止。
- 在相机会话启动后创建预览层，观察 isPreviewing；已有视频但预览未显示时重建一次连接，恢复失败显示明确错误。
- 独立于采集队列的启动超时检测也覆盖会话未启动或队列阻塞，不再只检查视频输出。

AVFoundation 返回的是相机坐标系下的深度；中央准心对应近似沿光轴的主体距离。
过滤只是稳定性检查，不能替代真实场景精度验证。反光、透明、低反射表面和遮挡边缘可能无有效读数。

接口参考：[Apple：使用 LiDAR 相机捕获深度](https://developer.apple.com/documentation/avfoundation/capturing-depth-using-the-lidar-camera)。

## 验证

```bash
bash scripts/test-rangefinder.sh
bash scripts/check-ios27-compatibility.sh
```

自动测试覆盖无效值、边界表面、读数平滑、目标切换、迟到帧、锁定/解锁和过期清除。
已通过 iOS 27.1 SDK 的模拟器 Debug、真机 Release 构建；
已在 iOS 26.4 模拟器检查启动、中央准心布局及无 LiDAR 回退状态。
2026-10-27 已在连接的 iPhone 16 Pro 安装修复版并启动：日志确认 LiDAR 相机配置成功、
会话运行、首帧到达及预览层 isPreviewing 为 true；真机截图确认实时取景和距离读数同时显示。
这验证了采集与预览链路，尚未验证卷尺对照精度及全部场景下的交互稳定性。

真机验收：

1. 在带 LiDAR 的 iPhone 上，对墙面/人物分别测量 0.5、1、2、4 m，使用卷尺记录误差与稳定性。
2. 点击底部标尺框的锁定按钮后移动手机，确认橙色读数保持；解锁后确认重新测量，且不会新增测光点。
3. 在标尺框以外点击添加测光点，确认实时取景、胶片选择和曝光操作保持可用。
4. 对玻璃、镜面、前后景边界、超过工作范围的目标，检查不会显示错误的稳定距离。
5. 测试相机权限拒绝/允许、前后台切换、相机被其他应用占用；确认旧读数不会冒充实时数据。
6. 在无 LiDAR 的 iPhone 上，确认显示不支持提示，实时测光仍可用。
