## 1. 测试概述

### 1.1 测试目标

验证Zone高亮框快门控制功能的正确性、稳定性和性能，确保符合设计文档要求。

### 1.2 测试范围

- 基础快门偏移功能
- 测光点移动逻辑
- 拖动交互
- 边界处理
- 性能表现
- 兼容性

### 1.3 测试环境

| 项目 | 要求 |
|------|------|
| iOS版本 | iOS 26.0+ |
| 设备 | iPhone 16 Pro（主测）、iPhone 15 Pro（兼容） |
| Xcode | 16.0+ |
| Swift | 6.0 |
