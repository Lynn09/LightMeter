### Task 2.3: 创建 ExposureCalculator 曝光计算工具

**文件**: `LightMeter/Models/ExposureCalculator.swift`

**实现内容**:
- 定义 `ExposureCalculator` 结构体
- 方法：
  - `brightnessToEV(brightness: Double) -> Double`
    - 将亮度值转换为EV值
    - 公式: EV = log2(L/K)，其中K=12.5

  - `evToZone(ev: Double, referenceEV: Double = 12.5) -> Int`
    - 将EV映射到Zone
    - 公式: Zone = Int((ev - referenceEV) + 5)
    - 返回限制在0-10范围内

  - `calculateExposureAdjustment(currentZones: [Int], targetZone: Int = 5) -> Double`
    - 计算曝光调整档数
    - 返回: Double 表示需要调整的档数（正数增加曝光，负数减少）

  - `calculateAperture(baseAperture: Double, stops: Double) -> Double`
    - 根据调整档数计算光圈值
    - 公式: aperture = baseAperture * pow(2.0, stops / 2.0)

  - `formatAperture(_ aperture: Double) -> String`
    - 格式化光圈值为字符串
    - 支持 f/1.4, f/2, f/2.8, f/4, f/5.6, f/8, f/11, f/16, f/22

  - `formatShutterSpeed(_ speed: Double) -> String`
    - 格式化快门速度为字符串
    - 支持 1/4000s, 1/2000s, 1/1000s, 1/500s, 1/250s, 1/125s, 1/60s, 1/30s, 1s

**功能概述：**
实现曝光参数显示栏和曝光计算逻辑，包括光圈、快门、ISO显示和曝光计算算法。

**详细任务：**

#### Task 6.1: 创建 ExposureInfoView.swift 曝光参数栏
**文件**: `LightMeter/Views/ExposureInfoView.swift`
- 三个参数显示：光圈、快门、ISO
- 每个参数包含：标签（光圈/快门/ISO）和数值
- 数值使用大号字体（28pt）
- 分隔线分隔三个参数
- 整体布局和样式

#### Task 6.2: 在 ViewModel 中实现曝光计算逻辑
- 根据测光点计算平均 Zone
- 计算目标 Zone（通常是 Zone V）与当前平均 Zone 的差异
- 计算 EV 值：EV = 12.5 + diff
- 计算光圈值：baseAperture * pow(2.0, diff / 2.0)
- 计算快门速度
- 根据胶片 ISO 设置 ISO 值

#### Task 6.3: 实现曝光参数格式化
- 光圈格式：f/8, f/5.6, f/11 等
- 快门格式：1/125s, 1/60s, 1/250s 等
- ISO 格式：50, 100, 200 等
