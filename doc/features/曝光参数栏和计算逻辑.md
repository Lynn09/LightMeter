# Feature: 曝光参数栏和计算逻辑

## 功能概述

实现曝光参数显示栏和曝光计算逻辑，包括光圈、快门、ISO显示和曝光计算算法。根据测光结果自动计算推荐的曝光参数。

## 当前状态

- [x] 已完成

## 目标

根据测光点数据自动计算并显示推荐的曝光参数：
- 根据测光点的平均 Zone 计算 EV 值
- 计算推荐的光圈值
- 计算推荐的快门速度
- 显示当前胶片的 ISO 值

### Task 6.2: 实现曝光计算逻辑

**文件**: `LightMeter/ViewModels/MeteringViewModel.swift`（在 ViewModel 中实现）

**实现内容**:

**A. 曝光参数属性**:
```swift
@Published var currentEV: Double = 12.5
@Published var aperture: String = "f/8"
@Published var shutterSpeed: String = "1/125s"
@Published var iso: Int = 50
```

**B. 曝光计算方法 `updateExposureValues()`**:

```swift
private func updateExposureValues() {
    guard !meteringPoints.isEmpty else { return }

    // 1. 计算测光点的平均 Zone
    let avgZone = meteringPoints
        .map { Double($0.zone) }
        .reduce(0, +) / Double(meteringPoints.count)

    // 2. 目标 Zone 是 Zone V（中间调）
    let targetZone = 5.0

    // 3. 计算需要的调整档数
    let diff = targetZone - avgZone

    // 4. 计算 EV 值
    // 基准 EV 12.5 对应 Zone V
    currentEV = 12.5 + diff

    // 5. 计算光圈值
    let baseAperture = 8.0
    let apertureValue = baseAperture * pow(2.0, diff / 2.0)

    // 格式化光圈值
    if apertureValue <= 1.4 {
        aperture = "f/1.4"
    } else if apertureValue >= 22 {
        aperture = "f/22"
    } else {
        // 取最近的整档光圈
        let standardApertures = [1.4, 2.0, 2.8, 4.0, 5.6, 8.0, 11.0, 16.0, 22.0]
        let closest = standardApertures.min { abs($0 - apertureValue) < abs($1 - apertureValue) } ?? 8.0

        if closest == trunc(closest) {
            aperture = "f/\(Int(closest))"
        } else {
            aperture = "f/\(closest)"
        }
    }

    // 6. 计算快门速度（简化版，实际需要考虑更多因素）
    // 这里使用一个简化公式
    let baseShutterSpeed = 125.0  // 1/125s
    let shutterValue = baseShutterSpeed * pow(2.0, diff)

    // 格式化快门速度
    if shutterValue >= 1000 {
        shutterSpeed = "1/\(Int(shutterValue))s"
    } else if shutterValue >= 100 {
        shutterSpeed = "1/\(Int(shutterValue))s"
    } else if shutterValue >= 60 {
        shutterSpeed = "1/60s"
    } else if shutterValue >= 30 {
        shutterSpeed = "1/30s"
    } else if shutterValue >= 15 {
        shutterSpeed = "1/15s"
    } else if shutterValue >= 8 {
        shutterSpeed = "1/8s"
    } else if shutterValue >= 4 {
        shutterSpeed = "1/4s"
    } else if shutterValue >= 2 {
        shutterSpeed = "1/2s"
    } else if shutterValue >= 1 {
        shutterSpeed = "1s"
    } else {
        shutterSpeed = "1/125s"
    }

    // 7. 设置 ISO 为当前胶片的 ISO
    iso = currentFilm.iso
}
```

**C. 触发曝光计算**:
- 在添加测光点后调用 `updateExposureValues()`
- 在删除测光点后调用 `updateExposureValues()`
- 在重新测光后调用 `updateExposureValues()`
- 在切换胶片后调用 `updateExposureValues()`（因为ISO会变）

## 备注

- 曝光计算逻辑比较复杂，建议先写单元测试验证计算公式的正确性
- 光圈和快门的标准档位需要考虑，可以使用标准序列：
  - 光圈：f/1.4, 2, 2.8, 4, 5.6, 8, 11, 16, 22
  - 快门：1/4000, 1/2000, 1/1000, 1/500, 1/250, 1/125, 1/60, 1/30, 1/15, 1/8, 1/4, 1/2, 1"
- 当前实现是简化版，实际相机测光需要考虑更多因素（ISO、场景模式等）
