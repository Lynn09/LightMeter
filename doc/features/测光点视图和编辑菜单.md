# Feature: 测光点视图和编辑菜单

## 功能概述

实现测光点标记视图和编辑菜单，包括彩色方框标记、发光效果、编辑菜单的功能按钮。用户点击画面添加测光点，点击测光点可以编辑或删除。

## 当前状态

- [x] 已完成

## 目标

提供完整的测光点交互功能：
- 在取景画面上显示彩色方框测光点标记
- 点击测光点弹出编辑菜单
- 支持删除测光点和重新测光
- 限制最多5个测光点

**实现内容**:

- 填充: 半透明（20%透明度），使用 `point.color`

**B. 选中时的发光效果**:

- 圆角: 10pt
- 边框: 2pt，颜色使用 `point.color`，透明度 50%
- 模糊效果: `blur(radius: 4)`

**C. 布局**:
```swift
ZStack {
    // 发光效果（选中时）
    if point.isSelected {
        RoundedRectangle(cornerRadius: 10)
            .stroke(Color(hex: point.color).opacity(0.5), lineWidth: 2)
            .frame(width: 70, height: 70)
            .blur(radius: 4)
    }

    // 主方框
    RoundedRectangle(cornerRadius: 6)
        .stroke(Color(hex: point.color), lineWidth: 3)
        .background(
            RoundedRectangle(cornerRadius: 6)
                .fill(Color(hex: point.color).opacity(0.2))
        )
        .frame(width: 50, height: 50)
}
.position(x: point.x, y: point.y)
.onTapGesture { onTap() }
```

### Task 5.4: 在 ViewModel 中实现测光点管理逻辑

**文件**: `LightMeter/ViewModels/MeteringViewModel.swift`

**实现内容**:

**属性**:
- `meteringPoints: [MeteringPoint] = []` - 测光点数组
- `selectedPoint: MeteringPoint?` - 当前选中的测光点

**方法**:

**A. 添加测光点**:
```swift
func addMeteringPoint(at location: CGPoint) {
    // 限制最多5个测光点
    guard meteringPoints.count < 5 else { return }

    // 分配颜色
    let colorIndex = meteringPoints.count % MeteringPoint.colors.count
    let color = MeteringPoint.colors[colorIndex]

    // 模拟测光计算（后续需要实际相机测光）
    let zone = Int.random(in: 3...8)
    let ev = Double(zone) + Double.random(in: 0...1)

    let point = MeteringPoint(
        x: location.x,
        y: location.y,
        color: color,
        zone: zone,
        ev: ev
    )

    meteringPoints.append(point)
    updateExposureValues()
}
```

**B. 选择测光点**:
```swift
func selectPoint(_ point: MeteringPoint) {
    // 重置所有点的选中状态
    for index in meteringPoints.indices {
        meteringPoints[index].isSelected = false
    }

    // 设置选中状态
    if let index = meteringPoints.firstIndex(where: { $0.id == point.id }) {
        meteringPoints[index].isSelected = true
        selectedPoint = meteringPoints[index]
    }
}
```

**C. 删除测光点**:
```swift
func deletePoint(_ point: MeteringPoint) {
    meteringPoints.removeAll { $0.id == point.id }
    selectedPoint = nil
    updateExposureValues()
}
```

**D. 重新测光**:
```swift
func retakeMetering(for point: MeteringPoint) {
    if let index = meteringPoints.firstIndex(where: { $0.id == point.id }) {
        // 模拟重新测光
        let zone = Int.random(in: 3...8)
        let ev = Double(zone) + Double.random(in: 0...1)

        meteringPoints[index].zone = zone
        meteringPoints[index].ev = ev
        selectedPoint = meteringPoints[index]
        updateExposureValues()
    }
}
```
