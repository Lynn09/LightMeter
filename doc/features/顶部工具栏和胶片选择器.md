### Task 3.3: 在 ViewModel 中实现胶片切换逻辑

**文件**: `LightMeter/ViewModels/MeteringViewModel.swift`

**实现内容**:
- 属性 `currentFilm: FilmPreset` - 当前选中的胶片，默认 Velvia 50
- 属性 `showingFilmSelector: Bool` - 是否显示胶片选择弹窗
- 方法 `changeFilm(_ film: FilmPreset)` - 切换胶片
  - 更新 currentFilm
  - 更新 ISO 值为新胶片的 ISO
  - 触发曝光参数重新计算
  - 更新11区梯度条的宽容度标记

**与 View 的绑定**:
- TopToolbar 显示 currentFilm.name
- TopToolbar 显示当前 EV 值（从 ViewModel 获取）
- FilmSelectorView 绑定到 currentFilm 和 showingFilmSelector
