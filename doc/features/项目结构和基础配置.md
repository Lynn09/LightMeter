## 详细任务

### Task 1.1: 创建 Xcode 项目文件
- 创建 `.xcodeproj` 项目文件
- 配置 Bundle ID: `com.yourname.LightMeter`
- 设置 Target iOS 版本: iOS 16.0+
- 配置项目名称: LightMeter

### Task 1.2: 创建目录结构
- 创建 `Models/` 目录
- 创建 `Views/` 目录
- 创建 `ViewModels/` 目录
- 创建 `Resources/` 目录
- 创建 `Utils/` 目录（可选）

### Task 1.3: 配置 Info.plist
- 添加 `NSCameraUsageDescription`: "LightMeter需要访问相机以提供实时测光功能"
- 配置 `UIUserInterfaceStyle`: `Dark`（强制深色模式）
- 设置 `UISupportedInterfaceOrientations`: 仅 Portrait

### Task 1.4: 创建应用入口文件
- 创建 `LightMeterApp.swift`
- 设置 `@main` 入口点
- 配置基础主题和颜色方案
- 初始化全局状态

### Task 1.5: 配置基础主题
- 设置全局深色主题
- 配置系统字体（SF Pro）
- 设置基础颜色（黑色背景、白色文字）
